# Chiaki + GBFR 自动重战使用说明

## 第一次使用

1. 完整解压 ZIP；保持解压后的文件夹名称为 `GBFR`，不要在压缩包预览中直接运行。
2. 双击 `使用本机稳定配置.cmd`（或 `启动工具.cmd`），在 Windows 弹出管理员权限提示时点击“是”。
   本机稳定配置固定使用 `Chiaki | Stream`，并按本机已验证的 `W/S/A/D=左摇杆上/下/左/右`、
   `Q/E=右摇杆左/右`、
   `Return=Cross`、`\`=Square、`L=L2`、`3=R1` 启动，默认不反向移动。
3. 点击“启动 Chiaki”，在 Chiaki 中完成 PS5 主机注册并连接串流。
4. 在 Chiaki 的按键设置中确认：`W/S/A/D` = 左摇杆上/下/左/右、`Q/E` = 右摇杆左/右、
   `Return` = Cross、`\` = Square、
   `3` = R1、`L` = L2。工具不再识别战斗前“跳过”，也不会发送 Backspace；
   自动化不需要配置 Touchpad。原 PC 工具的鼠标中键是“锁定目标”，手柄等效按键是
   L2，不能替换成 DS4 Touchpad，否则可能打开“奥义指示”圆盘并遮住技能状态。
5. 需要后台运行时，勾选“后台运行”，点击“检查后台环境”。
   这个选项会独立保存到当前 Windows 用户配置，关闭或重新打开工具后仍保持原值；
   环境检查不会替你开启或关闭它。自动重战运行期间该选项会锁定，停止后才能切换。
   配置文件位于 `%LOCALAPPDATA%\GBFR-AutoReBattle\settings.json`，不会写进绿色包，
   因而每台客户机分别保存自己的后台模式选择。
6. 若提示缺少虚拟手柄驱动，点击“安装 ViGEmBus”；Windows 会要求确认驱动安装。
   安装完成后回到工具再点一次“检查后台环境”。“安装 HidHide”是独立的可选按钮，
   只有实体手柄与虚拟 DS4 同时被接收、出现重复输入或方向冲突时才需要使用。
   两个按钮互不串联，工具不会自动修改 HidHide 的隐藏列表或白名单；安装 HidHide 后，
   请按需打开 `HidHide Configuration Client` 手动选择要隐藏的实体设备。
7. 检查结果会显示实际输入链路和 DS4 的 `bThumbLY` 值。若客户机后台运行时角色
   方向相反，只勾选“反向移动方向（仅后台客户机方向相反时）”，再重新启动自动重战。
8. 点击“启动自动重战”。任何时候按 `F2` 都可以停止自动化，按 `F3` 可以暂停/继续；
   暂停时会立即释放前进、转向、镜头和 L2 等自动化输入，不会重置当前战斗阶段。

## 运行统计与定时结束

主界面的“本轮挂机统计”会显示已完成场数、当前场耗时、上一场耗时、平均/最快/最慢
耗时，并列出每场的结算时间。统计同时保存为
`%LOCALAPPDATA%\GBFR-AutoReBattle\logs\session-stats.json`，不依赖 OCR 日志文本。

在“自动结束设置”中填写一个或多个条件后，点击“应用设置”：完成场数、运行时长（分钟）、
自动关闭时间（本机时钟 `HH:MM`）。时间如果已经过去，则按次日该时间处理。任一条件满足后，
工具会释放输入、结束自动化并请求关闭 Chiaki；全部留空或填 0 则持续运行。运行过程中再次
修改并点击“应用设置”会立即更新当前任务，不需要重启自动重战。

战斗中如果上方或右侧技能持续高亮 15 秒，工具会暂停前进，短暂执行“后退 +
左/右交替移动 + 同方向扫镜头”的搜索弧线，并在转身进行到一半时发送一次 L2。
释放两个摇杆后先等待画面稳定 1.5 秒，再连续检查两帧技能亮度；这两帧只用于确认
本轮转身锁定结果，不会再次发送 L2，避免把已经成功的锁定切换掉。
搜索动作只在已确认的战斗阶段运行；检测到结算或中途停止时会先释放移动键，
不会在结算画面继续转向或补按 L2。

结算阶段先识别左下角的 `再次挑战` 并开启自动再次挑战（如果尚未开启），然后只在
先识别到 `BATTLE RESULTS`、再连续两帧识别到右下角“继续”时发送一次 Cross；提示
仍存在时可继续推进，提示消失就停止。结算确认弹窗只有在“是”高亮时才会确认。
这里不再使用固定次数限制，也不会在等待战斗入口时盲按 Cross。游戏自身的战斗前
自动跳过应保持开启。

性能方面，战斗状态每秒最多检查一次；固定位置文字（`跳跃`、`RES`、`继续`、
`再次挑战`）使用轻量单行识别，不运行完整文字检测模型。工具只预加载实际使用的
文字识别模型，检测和方向分类模型按需加载，并关闭 ONNX 线程池的空闲自旋。
后台 Chiaki 整帧缓存调整为每秒两帧；8 线程及以下 CPU 自动使用 1 个 OCR 计算线程，
更多线程的 CPU 使用 2 个，兼顾老四核平台占用和新平台识别延迟。
技能高亮监控平时每两秒一次，出现高亮后恢复每秒一次，并将两个技能合并为一次截图。

本绿色包已内置 `windows-capture`，不需要安装 Python。后台模式还需要
ViGEmBus 虚拟手柄驱动：双击包内的 `安装ViGEmBus.cmd`（旧名
`安装ViGEmBus驱动.cmd` 也保留），在官方驱动安装窗口中完成确认。HidHide
安装程序也放在 `Dependencies` 目录中，并可通过工具内的独立按钮或
`安装HidHide.cmd` 启动；它不是后台模式的必需组件。若安装程序要求重启 Windows，
请先重启再运行自动重战。

## 日志与问题排查

主界面下方显示实时运行日志，同时保存到
`%LOCALAPPDATA%\GBFR-AutoReBattle\logs`。日志使用 UTF-8 with BOM，
Windows 记事本和常用编辑器都应能正常显示中文。程序目录不再写日志，
因此可从微信文件接收目录启动；不过仍建议先完整解压到普通文件夹后使用。

后台模式允许其他窗口覆盖 Chiaki，但不要最小化 Chiaki。最小化后串流画面可能停止
更新，OCR 无法判断游戏状态。第一次建议先用前台模式测试按键映射，再打开后台模式。
后台模式不会调用窗口聚焦，也会复用已经存在的 Chiaki 串流窗口，不会重复启动 Chiaki。
黄色窗口边框表示 Windows 正在捕获该 Chiaki 窗口，不代表虚拟手柄是否生效。若关闭
旧 Chiaki 后打开一个新的同名串流窗口，工具会保留自动化运行状态并自动重绑后台捕获，
日志会显示新的窗口句柄；黄色边框也应随捕获绑定到新窗口。

## PSN AccountID

点击“获取 PSN AccountID”会打开 Sony 登录页面。登录完成后，将地址栏的完整 redirect
URL 粘贴回工具；生成的 AccountID 会复制到剪贴板。不要把 redirect URL、授权 code 或
AccountID 发到群聊、Issue、截图或日志中。
