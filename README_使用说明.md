# Chiaki + GBFR 自动重战使用说明

## 第一次使用

1. 完整解压 ZIP；保持解压后的文件夹名称为 `GBFR`，不要在压缩包预览中直接运行。
2. 双击 `使用本机稳定配置.cmd`（或 `启动工具.cmd`），在 Windows 弹出管理员权限提示时点击“是”。
   工具默认使用 `Chiaki | Stream` 作为串流窗口标题，不会覆盖用户现有的 Chiaki 键位；
   修改标题后点击“应用标题”，运行中的自动重战会立即请求重新捕获，未运行时会保存到
   下次启动配置；
   如果用户版本修改了标题，工具只会在已连接的 `Stream` / `串流` 窗口出现后自动捕获，
   不会把 Chiaki 主界面或本工具控制台写入标题框；自定义标题可手动填入后点“应用标题”。
   “Chiaki 程序”支持直接填入路径，
   也可以点击“自动查找”或“浏览”。运行中如果标题自动识别仍未成功，可点击“重新捕获
   串流窗口（F4）”重新枚举并绑定当前 Chiaki 窗口。工具优先发现
   便携包内置 Chiaki 和 Windows 常见安装/App Paths 位置。便携版不一定登记程序路径，
   自动查找无结果时浏览选择一次即可，路径只保存在本机设置中。
3. 点击“启动 Chiaki”，在 Chiaki 中完成 PS5 主机注册并连接串流。
4. 点击“一键同步输入配置”。工具会从
   `HKCU\Software\Chiaki\Chiaki\keymap` 读取已有键位，并与 Chiaki 2.2.0 默认键位合并；
   注册表没有保存的动作使用 Chiaki 默认值，不要求用户重新配置一遍。前台模式按同步后的
   实际键位发送；后台模式不依赖 Chiaki 键盘映射。工具不使用 Touchpad。
5. 需要后台运行时，勾选“后台运行”，点击“检查后台环境”。
   这个选项会独立保存到当前 Windows 用户配置，关闭或重新打开工具后仍保持原值；
   环境检查不会替你开启或关闭它。自动重战运行期间该选项会锁定，停止后才能切换。
   配置文件位于 `%LOCALAPPDATA%\GBFR-AutoReBattle\settings.json`，不会写进绿色包，
   因而每台客户机分别保存自己的后台模式选择。
6. 若后台环境检查提示缺少驱动，点击“安装 ViGEmBus”；Windows 会要求确认驱动安装。
   安装完成后回到工具再点一次“检查后台环境”。“安装 HidHide”是独立的可选按钮，
   只有实体手柄出现重复输入或方向冲突时才需要使用。
   两个按钮互不串联，工具不会自动修改 HidHide 的隐藏列表或白名单；安装 HidHide 后，
   请按需打开 `HidHide Configuration Client` 手动选择要隐藏的实体设备。
7. 若客户机后台运行时角色方向相反，只勾选
   “反向移动方向（仅后台客户机方向相反时）”，再重新启动自动重战。
8. 点击“启动自动重战”。任何时候按 `F2` 都可以停止自动化，按 `F3` 可以暂停/继续；
   暂停时会立即释放前进、转向、镜头和 L2 等自动化输入，不会重置当前战斗阶段。
   恢复时会先重新检查右下角“继续”和左下角“再次挑战/撤销”，确认不是结算画面后
   才恢复向前推进，避免暂停期间进入结算后继续按 W。

### 最短启动流程

1. 启动工具并确认 Chiaki 路径、串流窗口标题。
2. 启动 Chiaki，连接 PS5，点击“一键同步输入配置”。
3. 需要后台挂机时勾选“后台运行”，点击“检查后台环境”。
4. 按需设置卡死恢复和自动结束条件，并分别点击“保存重连设置”“应用设置”。
5. 点击“启动自动重战”即开始，不需要按 F1。主按钮会变为“自动重战生效，点击停止”，
   “本轮挂机统计”顶部的状态条会明确显示战斗中、结算推进、暂停或串流恢复。
   运行日志默认跟随最新内容；需要查看历史时点击“暂停自动滚动”，再拖动右侧滚动条。

### 运行中怎么判断是否正常

- `状态：战斗中`：已进入战斗阶段，工具会进行移动、技能监控和 L2 索敌。
- 日志出现“阶段切换: ... -> battle_active”：已正式开始战斗输入。
- 日志出现“识别到结算控件”：已进入结算流程，会处理再次挑战和继续提示。
- 日志出现“串流恢复完成，进入阶段”：重连已完成，工具正在把控制权交回自动重战。
- 窗口最小化或串流暂时没有新帧时，工具会释放自动输入；恢复窗口后会重新捕获，不要重复启动多个工具实例。

## 串流卡死恢复

主界面的“串流卡死恢复”区域可以单独配置，不会根据窗口标题猜测重连目标：

1. “Chiaki 程序”填写实际的 `chiaki.exe` 路径；该路径会保存到本机设置。
2. 优先点击“从 Chiaki 获取主机信息”。工具会读取当前 Windows 用户的 Chiaki 注册表，
   自动填入已保存的主机昵称和主机地址/IP；检测到多个目标时会让用户选择。确认后点击
   “保存重连设置”。如果 Chiaki 配置中没有可读目标，也可以手动填写这两项。
3. 勾选“画面持续静止后自动重连”，设置静止分钟数，再启动自动重战。正式挂机建议使用
   10 分钟；为了主动测试可以填写 `0.2` 分钟（约 12 秒），低于 2 分钟时工具会要求二次确认。
   卡死判定会结合画面低活动滚动比例、轻微抖动对齐，以及本轮历史平均/最长战斗耗时；
   不会因为单场战斗略长就直接重连。

如果需要直接从重连开始挂机，不想等待卡死阈值，可以点击同一区域的“一键重连并挂机”。
它会立即执行真实重连，识别并处理战斗、结算或主城接任务状态，恢复成功后接入完整自动挂机
主流程。挂机统计、自动结束、`F2` 停止、`F3` 暂停/继续和后续卡死监控均保持正常；自动
卡死监控是否勾选不影响这次手动重连动作。当前串流窗口已经消失时，一键重连会直接使用
Chiaki 的局域网发现协议读取 PS5 状态；检测到 `standby` 时自动发送唤醒包，并确认状态
变为 `ready` 后才打开串流，无需在 Chiaki 主窗口中双击主机或手动确认唤醒。若网络阻止
状态查询，日志会显示“未收到 PS5 状态响应”，再按兼容模式继续尝试连接。
随后使用保存的固定目标启动串流；仍有冻结窗口时，只关闭并替换当前自动化绑定的 Chiaki 进程。

触发恢复时，工具只关闭当前自动化已经绑定的 Chiaki 进程，然后使用保存的
`chiaki.exe stream <主机昵称> <主机地址>` 启动新串流，并按新进程绑定窗口。恢复后的画面
按以下顺序处理：先识别战斗 HUD 和结算控件；若画面稳定，优先按一次 L2 探测主城，只有识别到
“任务中心”才执行主城中的上一次任务流程；探测不到时不会继续盲按。动画/加载期间不额外发送
Cross，等待状态落定。串流重新建立后会先发送两次 Moon（前台为 `Backspace`，后台为
DS4 Circle）返回游戏画面；若仍识别到“主菜单”或“持有物”等菜单，会继续用 Moon 逐层
关闭。恢复失败会释放所有输入并停止自动化，避免角色一直按 W。

## 运行统计与定时结束

主界面的“本轮挂机统计”会显示已完成场数、当前场耗时、上一场耗时、平均/最快/最慢
耗时，并列出每场的结算时间。统计同时保存为
`%LOCALAPPDATA%\GBFR-AutoReBattle\logs\session-stats.json`，不依赖 OCR 日志文本。

在“自动结束设置”中填写一个或多个条件后，点击“应用设置”：完成场数、运行时长（分钟）、
自动关闭时间（本机时钟 `HH:MM`）。时间如果已经过去，则按次日该时间处理。任一条件满足后，
工具会释放输入、结束自动化并请求关闭 Chiaki；全部留空或填 0 则持续运行。运行过程中再次
修改并点击“应用设置”会立即更新当前任务，不需要重启自动重战。

战斗中如果上方或右侧技能持续高亮 15 秒，工具会暂停前进，短暂执行“后退 +
左/右交替移动 + 同方向扫镜头”的搜索弧线，并在转身进行到一半时发送一次 L2。
释放两个摇杆后先等待画面稳定 1.5 秒，再连续检查两帧技能亮度；这两帧只用于确认
本轮转身锁定结果，不会再次发送 L2，避免把已经成功的锁定切换掉。
搜索动作只在已确认的战斗阶段运行；检测到结算或中途停止时会先释放移动键，
不会在结算画面继续转向或补按 L2。

结算入口使用左下角的 `再次挑战/撤销` 与右下角“继续”控件，不读取左上方的结果标题。
进入结算后先开启自动再次挑战（如果尚未开启），再连续两帧识别到右下角“继续”时
发送一次 Cross；提示仍存在时可继续推进，提示消失就停止。结算确认弹窗只有在“是”
高亮时才会确认。
这里不再使用固定次数限制，也不会在等待战斗入口时盲按 Cross。游戏自身的战斗前
自动跳过应保持开启。

性能方面，战斗状态每秒最多检查一次；固定位置文字（`跳跃`、`继续`、
`再次挑战/撤销`）使用轻量单行识别，不运行完整文字检测模型。工具只预加载实际使用的
文字识别模型，检测和方向分类模型按需加载，并关闭 ONNX 线程池的空闲自旋。
后台 Chiaki 整帧缓存调整为每秒两帧；8 线程及以下 CPU 自动使用 1 个 OCR 计算线程，
更多线程的 CPU 使用 2 个，兼顾老四核平台占用和新平台识别延迟。
技能高亮监控平时每两秒一次，出现高亮后恢复每秒一次，并将两个技能合并为一次截图。

本绿色包已内置运行组件，不需要安装 Python。缺失环境按主界面的检查结果使用对应的
独立安装按钮即可；若安装程序要求重启 Windows，请先重启再运行自动重战。

## 日志与问题排查

主界面下方显示实时运行日志，同时保存到
`%LOCALAPPDATA%\GBFR-AutoReBattle\logs`。日志使用 UTF-8 with BOM，
Windows 记事本和常用编辑器都应能正常显示中文。程序目录不再写日志，
因此可从微信文件接收目录启动；不过仍建议先完整解压到普通文件夹后使用。
点击启动后，启动器状态会直接显示；OCR/ONNX 加载进度也会在日志中显示。首次运行若被
Windows Defender 扫描拖慢，日志仍应即时显示当前加载阶段，而不是长时间保持空白。

后台模式允许其他窗口覆盖 Chiaki。误最小化时自动重战会暂停画面判断；恢复 Chiaki
窗口后，工具会重新绑定后台捕获并继续当前阶段，不需要重开工具或串流。最小化期间
OCR 不判断游戏状态。第一次建议先用前台模式测试按键映射，再打开后台模式。
后台模式不会调用窗口聚焦，也会复用已经存在的 Chiaki 串流窗口，不会重复启动 Chiaki。
黄色窗口边框表示 Windows 正在捕获该 Chiaki 窗口，不代表虚拟手柄是否生效。若关闭
旧 Chiaki 后打开一个新的同名串流窗口，工具会保留自动化运行状态并自动重绑后台捕获，
日志会显示新的窗口句柄；黄色边框也应随捕获绑定到新窗口。

## PSN AccountID

点击“获取 PSN AccountID”会打开 Sony 登录页面。登录完成后，将地址栏的完整 redirect
URL 粘贴回工具；生成的 AccountID 会复制到剪贴板。不要把 redirect URL、授权 code 或
AccountID 发到群聊、Issue、截图或日志中。
