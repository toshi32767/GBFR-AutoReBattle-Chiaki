# Contributing

Before opening a pull request, read `PUBLISH_BLOCKERS.md` and `NOTICE.md`.
Until upstream redistribution permission is resolved, keep discussions and
patches in a private repository.

For functional changes, include:

- The Chiaki version, Windows version, stream resolution, and exact key map.
- Reproduction steps with private data removed.
- A sanitized automation log or a screenshot with AccountID, host address, and
  OAuth redirect parameters redacted.
- The command used for verification.

Do not submit Chiaki binaries, DLLs, PSN credentials, registration files,
captured streams, or large build folders.
